# Radar Urbex

Carte interactive des lieux abandonnés, en ruine ou désaffectés autour de soi.

En ligne : https://alexandredts2005.github.io/radar-urbex/

Les données sont interrogées en direct, sans compte ni clé :

- OpenStreetMap (Overpass) pour les lieux
- Wikidata et Wikipédia pour l'histoire
- Wikimedia Commons pour les photos
- IGN pour les vues aériennes, dont celle de 1950-1965
- OSRM pour les itinéraires

Un lieu abandonné a presque toujours un propriétaire : demander l'autorisation avant d'entrer.
